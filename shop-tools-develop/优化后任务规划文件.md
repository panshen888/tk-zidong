# 1688 识图找货源自动化系统任务规划

> 基于 `初步任务规划.md` 优化整理。源文件保持不变，本文件作为后续实施基准。

## 1. 项目定位

本项目是一个基于 Electron + React 的桌面端自动化工具，用于将选品 Excel 中的商品主图提交到 1688“以图搜款”，抓取相似货源候选，并将候选链接、SKU 价格、MOQ、克重、供应商信息、评分与风险备注回填到输出 Excel。

核心价值：

- 降低人工逐个搜图找货源的时间成本。
- 固化 1688 搜图、候选抓取、详情解析、评分排序、Excel 回填流程。
- 通过任务日志与资产目录沉淀可追踪的批量处理结果。

## 2. 当前范围

### 2.1 MVP 范围

第一阶段优先实现可闭环的最小可用版本：

1. Electron 桌面应用基础框架。
2. React 三个路由菜单：
   - 首页
   - 任务列表页
   - 全局配置页
3. 创建任务：
   - 上传 Excel 文件。
   - 配置本次任务抓取的 1688 候选链接数。
   - 若未配置，则使用全局默认值。
4. 读取 Excel 中的商品主图：
   - 优先读取行内嵌图片。
   - 无内嵌图片时读取 `原商品主图URL`。
5. 缓存图片到本地任务资产目录。
6. 调用本地已登录 Chrome 访问 1688。
7. 使用 1688 以图搜款并抓取前 N 个候选链接。
8. 输出 Excel：
   - 回填 `选品表`。
   - 生成 `1688候选供应商` Sheet。
9. 任务日志：
   - 记录每行商品处理状态。
   - 支持快速打开当前任务 Excel 与资产目录。

### 2.2 后续增强范围

第二阶段及以后再逐步加入：

- 进入详情页解析 SKU、价格、MOQ、克重。
- 供应商评分模型优化。
- 失败重试、断点续跑、并发控制。
- DOM 结构变更适配器。
- 更细粒度的风险识别与人工复核入口。

## 3. 目标流程

```text
选择 Excel 文件
  ↓
创建任务并生成任务目录
  ↓
读取 Sheet「选品表」
  ↓
逐行提取内嵌图片或主图 URL
  ↓
缓存图片到本地
  ↓
调用本地 Chrome 打开 1688
  ↓
上传图片执行“以图搜款”
  ↓
抓取前 N 个候选货源链接
  ↓
可选进入详情页解析 SKU / MOQ / 克重
  ↓
供应商评分与排序
  ↓
生成输出 Excel
  ↓
任务完成并沉淀日志
```

## 5. Excel 输入与输出规范

### 5.1 输入 Excel

Sheet 名：

```text
选品表
```

必填字段：

| 字段 | 说明 | 是否必填 |
|---|---|---|
| 原商品ID | 商品唯一编号 | 是 |
| 原商品链接 | TikTok / Shopee / Lazada 等原商品链接 | 否 |
| 原商品主图URL | 商品主图链接，无内嵌图片时使用 | 条件必填 |
| 商品标题 | 原商品标题 | 否 |
| 国家 | 站点或销售国家 | 否 |
| 类目 | 商品类目 | 否 |

图片读取规则：

1. 优先读取当前行内嵌图片。
2. 当前行无内嵌图片时读取 `原商品主图URL`。
3. 两者均不存在时标记为 `缺少主图`，不进入 1688 搜图。

### 5.2 输出 Excel

输出包含两个 Sheet：

1. `选品表`
2. `1688候选供应商`

#### 5.2.1 输出 Sheet：选品表

在原始字段基础上追加：

| 字段 | 说明 |
|---|---|
| 搜图状态 | 成功 / 未找到 / 缺少主图 / 失败 |
| 1688候选数 | 找到的候选供应商数量 |
| 推荐1688链接1 | 排名第一候选链接 |
| 推荐1688链接2 | 排名第二候选链接 |
| 推荐1688链接3 | 排名第三候选链接 |
| 最低可用SKU价 | 详情解析后回填 |
| MOQ | 起订量 |
| 克重 | 单品重量 |
| 克重置信度 | 高 / 中 / 低 |
| 供应商评分 | 系统评分 |
| 风险备注 | 采集异常、缺少克重、未打开详情页等 |

#### 5.2.2 输出 Sheet：1688候选供应商

| 字段 | 说明 |
|---|---|
| 原商品ID | 对应输入商品 |
| 1688链接 | 候选货源链接 |
| offerId | 1688 商品 ID |
| 商品标题 | 1688 商品标题 |
| 供应商 | 供应商名称 |
| 供应商类型 | 工厂 / 供应商 / 未识别 |
| 会员商家 | 是否识别为会员 |
| 主图URL | 1688 商品主图 |
| 最低SKU价 | SKU 最低价 |
| MOQ | 起订量 |
| 克重g | 单品重量，单位 g |
| 克重来源 | 属性 / 文本 / 详情页 / 未识别 |
| 克重置信度 | 高 / 中 / 低 |
| SKU摘要 | SKU 规格和价格摘要 |
| 风险标记 | 风险说明 |
| 评分 | 系统评分 |
| 建议 | 优先 / 备选 / 不建议 |

## 6. 技术模块拆分

### 6.1 Electron 主进程

职责：

- 应用窗口创建。
- IPC 通信注册。
- 文件选择、目录选择、打开文件位置。
- 调用本地 Chrome 或连接 Chrome 调试端口。
- 任务执行进程管理。

建议模块：

- `appWindow`
- `ipcHandlers`
- `fileDialog`
- `chromeLauncher`
- `taskRunner`

### 6.2 React 渲染进程

职责：

- 页面路由。
- 任务创建表单。
- 任务列表与日志展示。
- 全局配置管理。

建议模块：

- `routes/Home`
- `routes/Tasks`
- `routes/Settings`
- `components/TaskCreateDialog`
- `components/TaskLogPanel`
- `components/ConfigForm`

### 6.3 任务服务

职责：

- 创建任务。
- 持久化任务状态。
- 管理任务目录。
- 分发逐行处理流程。
- 记录日志。

建议能力：

- `createTask`
- `startTask`
- `pauseTask`（后续）
- `rerunFailedItems`
- `appendTaskLog`
- `updateTaskStatus`

### 6.4 Excel 服务

职责：

- 读取输入 Excel。
- 解析 Sheet 与字段。
- 提取行内嵌图片。
- 下载或缓存主图 URL 图片。
- 写入输出 Excel。

建议能力：

- `readSelectionSheet`
- `extractRowImage`
- `downloadImage`
- `buildOutputWorkbook`
- `writeOutputWorkbook`

### 6.5 1688 搜图适配器

职责：

- 打开 1688 搜图入口。
- 上传图片。
- 等待搜索结果。
- 解析候选商品卡片。
- 标准化候选链接与 offerId。

建议能力：

- `openImageSearch`
- `uploadImage`
- `waitForSearchResults`
- `parseCandidateCards`
- `normalizeOfferUrl`

注意：

- 1688 DOM 可能变化，应将选择器集中维护。
- 如需确认 DOM 结构，可使用已登录浏览器查询后再固化选择器。
- MVP 先单线程串行处理，降低登录态、反爬与页面状态风险。

### 6.6 详情解析适配器

职责：

- 打开候选商品详情页。
- 解析商品标题、SKU、价格、MOQ、克重、供应商信息。
- 识别克重来源与置信度。

MVP 可以先将其作为可选开关：

- 开启：抓取详情并补齐更多字段。
- 关闭：仅输出候选链接与基础卡片信息。

### 6.7 评分服务

职责：

- 对候选供应商进行排序和建议。
- 输出 `优先 / 备选 / 不建议`。

初始评分建议：

| 维度 | 权重建议 | 说明 |
|---|---:|---|
| 价格可用性 | 25 | 能识别 SKU 价且价格合理 |
| MOQ | 20 | 起订量越低越优 |
| 克重完整度 | 15 | 有克重且置信度高 |
| 供应商类型 | 15 | 工厂或稳定供应商优先 |
| 会员/信用信息 | 10 | 可识别会员或信用标识 |
| 标题/图片相似度 | 15 | 与原商品更接近者优先 |

## 8. 实施里程碑

### 阶段 1：项目骨架与基础页面

目标：完成 Electron + React 基础应用和三个路由菜单。

任务：

- 初始化 Electron + React 技术栈。
- 建立首页、任务列表页、全局配置页。
- 建立基础布局、导航菜单、状态展示组件。
- 接入 IPC 基础通信。

验收标准：

- 应用可启动。
- 三个页面可正常切换。
- 前端能通过 IPC 调用主进程基础接口。

### 阶段 2：任务创建与配置持久化

目标：可以创建任务并保存任务元信息。

任务：

- 实现 Excel 文件选择。
- 实现输出目录与资产目录配置。
- 实现候选抓取数量配置。
- 实现任务元数据保存。
- 实现任务列表读取与刷新。

验收标准：

- 可以从页面创建任务。
- 任务出现在任务列表。
- 任务目录结构正确生成。
- 全局配置重启后仍可读取。

### 阶段 3：Excel 读取与图片缓存

目标：能读取选品表并提取图片资产。

任务：

- 读取 Sheet `选品表`。
- 校验输入字段。
- 提取行内嵌图片。
- 下载 `原商品主图URL`。
- 将图片缓存到任务目录。
- 记录缺少主图的行。

验收标准：

- 能读取商品行。
- 能生成本地图片文件。
- 缺少主图时不会阻断整个任务。
- 日志能准确记录每行状态。

### 阶段 4：1688 以图搜款自动化

目标：能用本地 Chrome 完成搜图并抓取候选链接。

任务：

- 连接或启动本地 Chrome。
- 打开 1688 搜图入口。
- 上传本地图片。
- 等待搜索结果加载。
- 解析前 N 个候选商品链接。
- 标准化 offerId 与商品 URL。

验收标准：

- 单个商品可完成搜图。
- 能抓取配置数量内的候选链接。
- 搜图失败能写入日志与风险备注。
- 不因单行失败中断整个任务。

### 阶段 5：输出 Excel 生成

目标：形成端到端可用的 MVP。

任务：

- 生成输出 Sheet `选品表`。
- 生成输出 Sheet `1688候选供应商`。
- 回填搜图状态、候选数、推荐链接。
- 支持打开输出 Excel 所在目录。

验收标准：

- 任务完成后生成 `result.xlsx`。
- 输出字段与规划一致。
- 候选数据与原商品 ID 可关联。
- 任务列表显示完成状态与统计数。

### 阶段 6：详情页解析与评分

目标：补齐 SKU、MOQ、克重、供应商评分能力。

任务：

- 打开候选详情页。
- 解析 SKU 价格。
- 解析 MOQ。
- 解析克重及来源。
- 解析供应商名称、类型、会员信息。
- 实现初版评分函数。
- 输出建议：优先 / 备选 / 不建议。

验收标准：

- 开启详情解析后可补齐扩展字段。
- 克重有置信度。
- 候选供应商能按评分排序。
- 风险备注能说明缺失原因。

### 阶段 7：稳定性与体验优化

目标：提升批量任务稳定性和用户可控性。

任务：

- 加入失败重试。
- 加入超时控制。
- 加入断点续跑。
- 加入重新运行失败项。
- 优化日志面板。
- 增加常见错误提示。

验收标准：

- 批量任务失败率可观测。
- 用户能定位失败原因。
- 失败项可单独重跑。
- DOM 变更时便于替换选择器。

## 9. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 1688 DOM 结构变化 | 搜图或解析失败 | 集中维护选择器，保留调试日志 |
| Chrome 登录态失效 | 无法访问或结果异常 | 配置 Chrome 用户数据目录，提示用户重新登录 |
| 反爬或频控 | 批量任务中断 | MVP 串行处理，增加随机等待和失败重试 |
| Excel 内嵌图片解析复杂 | 图片提取失败 | 优先支持主流 xlsx 格式，失败时回退 URL |
| 克重字段不稳定 | 输出可信度不足 | 标记克重来源与置信度，不强行给高置信度 |
| 详情页加载慢 | 任务耗时过长 | 详情解析做成可选开关 |

## 10. 关键验收用例

### 用例 1：URL 主图输入

输入：

- Excel 中无内嵌图片。
- `原商品主图URL` 有效。

期望：

- 图片下载成功。
- 1688 搜图成功。
- 输出推荐链接与候选供应商 Sheet。

### 用例 2：内嵌图片输入

输入：

- Excel 行内存在商品图片。
- `原商品主图URL` 为空。

期望：

- 优先使用内嵌图片。
- 能完成搜图并输出候选。

### 用例 3：缺少主图

输入：

- 无内嵌图片。
- `原商品主图URL` 为空。

期望：

- 该行状态为 `缺少主图`。
- 不影响其他商品继续处理。

### 用例 4：1688 未找到候选

输入：

- 图片可上传。
- 1688 无有效候选结果。

期望：

- 搜图状态为 `未找到`。
- 候选数为 0。
- 风险备注记录原因。

### 用例 5：详情解析关闭

输入：

- 创建任务时关闭详情解析。

期望：

- 仅抓取候选链接。
- SKU、MOQ、克重为空或标记未解析。
- 任务仍可成功完成。

## 11. 推荐开发顺序

优先级从高到低：

1. 应用骨架与三页面路由。
2. 任务创建、配置、任务目录。
3. Excel 读取与图片缓存。
4. 单商品 1688 搜图自动化。
5. 批量任务串行处理。
6. 输出 Excel。
7. 详情页解析。
8. 评分排序。
9. 失败重试与断点续跑。

## 12. 需要用户确认的信息

后续正式实现前建议确认：

1. 1688 以图搜款入口的当前可用 URL。
2. 本地 Chrome 是否已开启远程调试端口，或是否需要应用自动启动 Chrome。
3. Excel 样例文件格式，尤其是内嵌图片所在行与商品字段的对应关系。
4. 输出 Excel 是否需要保留原表所有格式。
5. 供应商评分权重是否需要按业务策略调整。

## 13. MVP 完成定义

满足以下条件即可认为 MVP 完成：

- 用户能在桌面应用中新建任务。
- 系统能读取 Excel `选品表`。
- 系统能获取商品主图并缓存到本地。
- 系统能调用本地 Chrome 对 1688 执行以图搜款。
- 系统能抓取前 N 个候选链接。
- 系统能生成包含两个 Sheet 的输出 Excel。
- 任务列表能查看状态、日志，并快速打开输出资产目录。
