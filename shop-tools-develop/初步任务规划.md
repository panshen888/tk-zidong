# 1688 识图找货源自动化流程总结与迁移说明

## 1. 项目目标

本项目用于把选品表里的商品主图拿去 1688 做“以图搜款”，自动寻找相似货源商家，并把候选 1688 链接、SKU 价格、MOQ、克重、供应商评分等信息回填到 Excel 表格。本项目通过Electron实现，使用react技术栈。  
目前暂时先规划三个路由菜单，一个首页、一个任务列表页(有任务日志，支持快速打开当前任务的excel资产位置，支持创建任务，创建任务要上传excel文件，要配置抓取的货源链接数，默认区去哪聚配置)、一个全局配置页

当前目标流程：

```text
Excel选品表
  ↓
读取商品主图URL或表格内图片
  ↓
缓存图片到本地
  ↓
调用本地Chrome打开1688
  ↓
上传图片到1688“以图搜款”
  ↓
抓取前N个1688货源链接(N 放到全局配置)
  ↓
可选：进入详情页抓SKU、价格、MOQ、克重
  ↓
供应商打分排序
  ↓
回填到Excel输出表
```

在实现这个流程的开发过程中，如果需要调用浏览器查询网页的dom信息，你可以直接调起浏览器，我已经在浏览器里登录过了。如果需要某些dom结构可以向我询问，如果需要excel文件格式可以向我询问


## 2. Excel 输入表结构

输出表路径支持全局配置

Sheet 名：

```text
选品表
```
表字段：

| 字段 | 说明 |
|---|---|
| 原商品ID | 商品唯一编号 |
| 原商品链接 | TikTok/Shopee/Lazada 等原商品链接 |
| 原商品主图URL | 商品主图链接 |
| 商品标题 | 可选 |
| 国家 | 可选 |
| 类目 | 可选 |

如果表格里直接粘贴了图片，系统会优先读取该行内嵌图片；如果没有内嵌图片，则读取 `原商品主图URL`。

## 3. 输出表结构

输出表路径支持全局配置

输出包含两个 Sheet。

### 3.1 选品表

会回填：

| 字段 | 说明 |
|---|---|
| 搜图状态 | 成功 / 未找到 / 缺少主图 |
| 1688候选数 | 找到的候选供应商数量 |
| 推荐1688链接1 | 排名第一的候选链接 |
| 推荐1688链接2 | 排名第二的候选链接 |
| 推荐1688链接3 | 排名第三的候选链接 |
| 最低可用SKU价 | 后续详情页解析后回填 |
| MOQ | 后续详情页解析后回填 |
| 克重 | 后续详情页解析后回填 |
| 克重置信度 | 高 / 中 / 低 |
| 供应商评分 | 系统评分 |
| 风险备注 | 采集异常、缺少克重、未打开详情页等 |

### 3.2 1688候选供应商

保存完整候选供应商数据：

| 字段 | 说明 |
|---|---|
| 原商品ID | 对应原商品 |
| 1688链接 | 候选货源链接 |
| offerId | 1688 商品 ID |
| 商品标题 | 详情页标题 |
| 供应商 | 供应商名称 |
| 供应商类型 | 工厂/供应商等 |
| 会员商家 | 是否识别为会员 |
| 主图URL | 1688 商品图 |
| 最低SKU价 | SKU最低价 |
| MOQ | 起订量 |
| 克重g | 单品重量 |
| 克重来源 | 属性/文本/详情页等 |
| 克重置信度 | 高 / 中 / 低 |
| SKU摘要 | SKU规格和价格 |
| 风险标记 | 风险说明 |
| 评分 | 供应商评分 |
| 建议 | 优先/备选/不建议 |
